# Source provenance

The `neural_ode` API modules were extracted from the `neural_ode` directory in
the parent research workspace. The private `_core` implementation is adapted
from its `lib` directory; source headers credit Yulia Rubanova for the Latent
ODE implementation. The helper and likelihood modules contain only routines
needed by this package.
